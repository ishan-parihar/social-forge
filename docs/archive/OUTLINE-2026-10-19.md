# Switchpost — Remaining Implementation Gaps Outline (2026-10-19)

Successor to OUTLINE-2026-10-17.md. Working queue is now
**agent-facing token efficiency**: the repo grew to 367 MCP tools + ~54
CLI subcommand groups (~250 leaf subcommands) across 25+ providers, and
the agent surface (skill docs + tool schemas) has become the largest
context cost any agentic workflow pays. This outline replaces the
2026-10-17 outline as the working queue; its unfinished items
(credentialed live passes) are carried into §Wave E.

State today: 367 MCP tools, 658 tests, clippy `-D warnings` clean.
Tool-count assert sites: AGENTS.md (×3 lines) + providers.md.

Baseline gate (must hold at every commit):
`SQLX_OFFLINE=true cargo clippy --all-targets --locked -- -D warnings` +
`SQLX_OFFLINE=true cargo test --no-fail-fast` (X throttle caveat below).

Effort: **S** < a session-fraction, **M** one focused session, **L** multi-session.
